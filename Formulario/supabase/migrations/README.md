# Migraciones del CRM VisuaLed

Estas migraciones pertenecen únicamente al CRM privado. No modifican ni conectan el formulario público.

Las membresías se administran desde un entorno confiable de Supabase. El navegador solo puede leer la membresía propia cuando está activa y la sesión fue creada con el código de correo de un solo uso.
